# 💰 Finanzas App

> Una aplicación moderna y responsiva para la gestión de finanzas personales, control de ingresos, gastos y visualización de métricas en tiempo real.

![Estado del Proyecto](https://img.shields.io/badge/Estado-En_Desarrollo-green)

## ✨ Características Principales

* **📊 Dashboard Interactivo:** Visualización de métricas clave (Balance total, Ingresos vs. Gastos).
* **📱 Diseño 100% Responsivo:** Interfaz adaptada a móviles, tablets y escritorio (Layout fluido con Sidebar inteligente).
* **💸 Gestión de Registros:** CRUD completo para transacciones (Ingresos y Gastos).
* **🔐 Autenticación Segura:** Login y manejo de sesiones con JWT.
* **🎨 UI Moderna:** Estilizado con SCSS Modules y componentes reutilizables.
* **🌍 Formato Local:** Manejo automático de monedas y formatos de fecha según la región.

## 🛠️ Tecnologías Utilizadas

### Frontend
* **Core:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
* **Estilos:** SCSS (Sass) Modules + TailwindCSS (utilitarios)
* **Iconos:** [Lucide React](https://lucide.dev/)
* **Formularios:** React Hook Form
* **Gráficos:** Recharts (para visualización de datos)

### Backend (API)
* **Framework:** Java Spring Boot
* **Base de Datos:** (MySQL / PostgreSQL)
* **Seguridad:** Spring Security + JWT
